issue #4 里报的两个问题，一个是一直就有的，一个是我这边的疏忽。没有新功能。

## 禁区盖住打卡点，绕了等于没绕

生成路线的时候，绕完楼之后要把打卡点插回路径上，插的时候不管你刚才绕过了什么，直接插回原位。所以禁区只要盖住打卡点，刚绕出去又被拽回来。

拿一条直线穿一栋 24 米宽的楼、打卡点放楼正中量了一下：避让完楼里一个点都没有，插完打卡点又变回六个。

这事没法两全——打卡点必须经过，楼又不能穿。所以没去改那个插点的函数（改了打卡就失败了），改成把话说清楚：

- 生成的时候日志里会写「第几个打卡点落在禁区内部，那块禁区的避让对它无效」
- 存禁区之前会先比对已有的打卡点，被盖住的当场列出来，让你决定缩小区块还是硬存

想真绕开就把禁区缩小，或者挪开不要压住打卡点。

顺带说一句，另一个同类工具是把打卡点直接当路网的必经点去算路线的，压根不做绕行这一步，所以不会打架。我们走真实路网的那条路也是这么干的，只有几何兜底那条做不到。

## 一生成路线，点位就变了

点位缓存只存了一份。切一下围栏，之前那份就被顶掉，切回来只能重新问服务端；服务端每次给的点位集合又不一定一样，看着就是「生成一下点就变了」。

改成按围栏、锚点、目标距离分开存了，各留各的。上限 64 份，满了先清过期的，再淘汰最老的那一份，不会整表清空。
