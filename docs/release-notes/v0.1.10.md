
上一版把超时收紧，这一版解决「下次再卡，怎么一眼看出卡在哪」。

## 生成过程按阶段报耗时

`dry_run` 现在在每一步埋点，日志里直接给秒数：

```
[耗时] 校时+策略 0.3s
[耗时] 围栏 1.1s
[耗时] 打卡点 0.6s
[耗时] 建筑/水体 30.0s
[耗时] 拉路网 0.2s
[耗时] 规划 0.3s
[耗时] 采样+自检 0.1s · 全程 32.6s
```

哪一段突然变长，就是哪一段在等网络或算得慢。以前只有「拉路网…」这类开头，没有结尾，卡住时看不出是慢还是死。

## 控制台「网络自检」

坐标那一行多了一个按钮，点了以后逐个探：

- Overpass 三个端点：各发一个空 bbox 的极小查询，最多 8 秒
- 高德瓦片：拉一张固定瓦片，最多 6 秒

每项报「✓/✗、耗时、错误原因」，末尾给一句结论。在国内网络下最常见的输出是 Overpass 三项全 ✗、瓦片 ✓——那就说明生成该走瓦片，OSM 那几步只是白等。

自检只测连通性：不参与生成、不写缓存、失败不影响任何功能。
